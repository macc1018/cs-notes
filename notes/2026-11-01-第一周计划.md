# 第一周学习计划（2026-11-01 ~ 11-07）

> 目标：把 C 语言的地基打完，并且养成「每天提交」的习惯。
> 时间：工作日 1.5 小时，周末 3 小时。

## 一周安排

| 日期 | 主题 | 学（30 分钟） | 写（60 分钟） |
|---|---|---|---|
| 11/01 周日 | 第一个程序 | `main` / `#include` / `printf` / 编译运行 | `hello.c`：打印姓名、专业、一句目标 |
| 11/02 周一 | 变量与输入 | `int` `float` `char`、`scanf` | 输入两数算四则；输入半径算圆面积周长 |
| 11/03 周二 | 条件判断 | `if` / `else` / `switch`、比较运算 | 成绩等级、闰年判断、三数最大值 |
| 11/04 周三 | 循环 | `for` / `while`、`break` / `continue` | 九九乘法表、1~100 求和、素数判断、猜数字 |
| 11/05 周四 | 数组与字符串 | 数组、越界、`'\0'` | 10 个数求最大/平均；字符串反转 |
| 11/06 周五 | 函数 | 定义、参数、返回值、递归入门 | 把前三天的代码全部重构成函数 |
| 11/07 周六 | 小项目 | —— | 学生成绩统计：录入 N 人成绩 → 排序 → 输出平均/最高/最低 |

## 每天的时间模板

```
20:00 - 20:30   看课（只学一个知识点，别连着看三集）
20:30 - 21:30   自己写（关掉教程，凭记忆写，写不出再回看）
21:30 - 21:40   git add -A && git commit && git push，再记两行笔记
```

## 三条铁律

1. **不许复制粘贴**。教程代码看一遍、关掉、自己敲出来。
2. **报错先自己读 3 分钟**。`error:` 后面的英文就是答案。
3. **断一天不补，直接跳过**。补作业只会制造「我还跟得上」的错觉。

## 周六验收标准

- [ ] 不看资料，独立写出「输入 10 个成绩 → 排序 → 输出平均分」
- [ ] 能逐行解释每一行代码在干什么
- [ ] `git log` 里正好 7 个提交，`notes/` 里有复盘

做不到就再来一周。**基础慢一点没关系，糊弄过去才是真的亏。**
