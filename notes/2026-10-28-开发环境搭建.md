## 踩过的坑

**1. Python 3.12.16 下载返回 404**

3.12 分支进入「安全维护」阶段后只发布源码，不再提供 Windows 安装包。
换成 3.14.10（当前正式版）解决。

**2. Node.js 的 MSI 静默安装报 1603**

MSI 属于「全机安装」，必须管理员权限。
用 `Start-Process msiexec -Verb RunAs` 提权解决。

**3. VS Code 下载卡住不动**

官方 CDN 在国内经常「连得上但不给数据」。
解决：断点续传 `curl -C -` + 连续 45 秒无数据自动重连。

**4. github.com 打不开**

DNS 解析到的 IP（20.205.243.166）不通，但 GitHub 的其他节点是通的。
改 hosts 指向 `140.82.112.3` 后恢复正常。

## 配好的东西

- SSH 密钥：`ed25519`，已添加到 GitHub
- 验证命令：`ssh -T git@github.com`
